Application architecture

  1. GitHub Pages serves the custom UI and saves conversation history in the visitor's browser.
  2. An optional HTTPS gateway forwards the current conversation to the guarded local service.
  3. SEA-LION checks language and scope. Gemma 4 E2B generates the conversational answer using Tagalog instructions and relevant cultural references.
  4. The service returns the reply to the UI.
