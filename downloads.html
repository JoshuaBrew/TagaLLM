Application architecture

  1. GitHub Pages serves the custom UI and saves conversation history in the visitor's browser.
  2. For local chat, the UI forwards the current conversation to the local Gemma service.
  3. Gemma 4 E2B generates the answer using Tagalog instructions and relevant cultural references. The evaluated research setup also used SEA-LION for language and scope checks.
  4. The service returns the reply to the UI.
